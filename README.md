# MeterNator

Готовые сборки MeterNator для Windows x64.

Первый релиз готовится. После публикации стабильной версии она будет доступна
[по постоянной ссылке](https://github.com/Exemma/MeterNator-Releases/releases/latest).

## Установка

В разделе [Releases](https://github.com/Exemma/MeterNator-Releases/releases)
скачайте из Assets архив `MeterNator-v…-win-x64.zip`, распакуйте его целиком
и запустите `StendSetup.App.exe`. .NET входит в комплект сборки.
Драйвер оптопорта устанавливается отдельно.

Перед обновлением закройте программу и дождитесь завершения работы с приборами.
Распакуйте новую версию в отдельную папку. Пользовательские данные удалять не нужно.

Файлы `Source code`, автоматически добавляемые GitHub, не являются программой.
Тестовые версии отмечены `Pre-release`.
